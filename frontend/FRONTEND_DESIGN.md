# VerifyAI Frontend — Design Phase 1

## Locked design decisions
- Visual direction: Academic + Modern AI
- Primary brand: Indigo
- Theme: Light + Dark
- Sidebar: Collapsible
- Dashboard: Hybrid analytics + activity
- AI Detector: Paste + document upload
- Research Verification: Guided entry + research workspace
- Claim result: Verdict + Evidence split
- Typography: Manrope
- Logo: Open book + magnifying glass

## Current scope
This ZIP focuses on the frontend experience. Backend/LLM/API behavior is intentionally not redesigned here.

The app includes a preview/demo session so the UI can be explored without starting FastAPI. The existing API client remains in the project for the later integration phase.

## Run
```bash
npm install
npm run dev
```

Then open `http://localhost:5173`.

Use **Preview the frontend** on the login page to enter the demo workspace without the backend.
